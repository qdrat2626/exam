# منصة الاختبارات الذكية | Smart Exam Studio

منظومة اختبارات تفاعلية متطورة ومتكاملة مع قاعدة بيانات سحابية (Firebase Firestore)، تدعم إدارة الاختبارات، إنشاء الأسئلة عبر ملفات JSON، متابعة نتائج وأوقات المختبرين بالتفصيل، وتصدير التقارير، مع خلفية حية تفاعلية وتصميم متكيف 100% مع جميع الهواتف والأجهزة.

---

## الميزات الرئيسية

- **تسجيل دخول ذكي بالاسم الرباعي**: يتعرف تلقائياً على حسابات الطلاب والمشرفين (المشرف الافتراضي: **محمد منتصر محمد يونس**).
- **إنشاء وتعديل الاختبارات عبر JSON والمحرر المرئي**: نسخ نموذج سكريبت JSON جاهز، لصقه، ومراجعة وتعديل الأسئلة والخيارات والنقاط فورياً.
- **تخصيص كامل للوقت والمواعيد**: إمكانية جعل الاختبار بوقت محدد بالدقائق أو وقت مفتوح، وتحديد موعد بداية ونهاية أو تركه متاحاً دائماً.
- **قسم المختبرين وسجل النتائج**: استعراض أداء الطلاب، **الوقت المستغرق بالدقائق والثواني بدقة**، وتفاصيل الإجابات سؤالاً بسؤال.
- **تصدير رسائل بالنتائج**: تحديد جميع الطلاب أو طلاب محددين ونسخ تقرير نصي منسق وجاهز للنشر عبر واتساب أو تليجرام.
- **إدارة الحسابات**: إضافة حسابات، ترقية أي حساب إلى رتبة مشرف، وحذف الحسابات أو نتائج الطلاب مع نوافذ تأكيد تفاعلية.
- **خلفية حية تفاعلية**: إضاءات متدرجة ناعمة تسبح في الخلفية مع أشكال هندسية متطايرة تضفي طاقة وحيوية.
- **متجاوب 100%**: متوافق تماماً مع الهواتف الذكية (بالوضع الطولي والأفقي)، الأجهزة اللوحية، وشاشات الكمبيوتر.

## التهيئة لنشر المشروع على GitHub و GitHub Pages (دون شاشة بيضاء)

تم تجهيز هذا المشروع هندسياً ليعمل على **GitHub Pages** بنسبة 100% دون مواجهة مشكلة الشاشة البيضاء الشائعة (`White Screen of Death`):
1. **المسارات النسبية (`base: './'`)**: تم ضبطها في `vite.config.ts` لضمان تحميل جميع ملفات الـ JS والـ CSS سواء كان المستودع في المسار الرئيسي أو مسار فرعي (`https://username.github.io/repo-name/`).
2. **تخطي Jekyll (`.nojekyll`)**: موجود داخل مجلد `public/` لتفادي تجاهل الملفات والمجلدات الخاصة بـ Vite.
3. **توجيه الروابط وتحديث الصفحة (`404.html`)**: ملف إعادة توجيه ذكي لمنع ظهور خطأ 404 عند تحديث الصفحة أو التنقل المباشر.
4. **أتمتة النشر التلقائي (`GitHub Actions`)**: ملف سير العمل `.github/workflows/deploy.yml` موجود وجاهز للبناء والنشر التلقائي مع كل `git push`.

## خطوات النشر على GitHub خطوة بخطوة

### 1. إنشاء مستودع جديد على حسابك في GitHub
- افتح موقع [GitHub](https://github.com/) وسجل الدخول.
- اضغط على زر **New Repository**.
- سمّ المستودع بأي اسم تريده (مثلاً: `exam-studio` أو `smart-exams`).
- اتركه عاماً (**Public**)، ولا تضع علامة على "Initialize with README".
- اضغط **Create repository**.

### 2. رفع الملفات من جهازك
افتح الطرفية (Terminal أو Git Bash) في مجلد المشروع، ونفذ الأوامر التالية:

```bash
# 1. تهيئة مستودع Git
git init

# 2. إضافة جميع الملفات
git add .

# 3. حفظ التعديلات
git commit -m "الإصدار الأول: منصة الاختبارات الذكية مهيأة للنشر"

# 4. تسمية الفرع الرئيسي
git branch -M main

# 5. ربط المستودع بحسابك (استبدل YOUR-USERNAME و YOUR-REPO بروابطك)
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git

# 6. رفع الكود
git push -u origin main
```

---

## 3. تفعيل الاستضافة المجانية على GitHub Pages (خلال دقيقة واحدة)

بمجرد رفع الكود:
1. اذهب إلى صفحة المستودع على GitHub.
2. اضغط على تبويب **Settings** في الأعلى.
3. من القائمة الجانبية اليسرى، اضغط على **Pages**.
4. تحت قسم **Build and deployment**:
   - في خانة **Source**، اختر: **GitHub Actions**.
5. سيقوم GitHub تلقائياً بتشغيل ملف سير العمل الموجود في المستودع (`.github/workflows/deploy.yml`).
6. انتظر دقيقة واحدة حتى تكتمل علامة الصح الخضراء (Green Checkmark).
7. سيظهر لك رابط موقعك المباشر في نفس الصفحة أعلى الشاشة:
   `https://YOUR-USERNAME.github.io/YOUR-REPO/`

افتح الرابط وستعمل المنصة بكامل طاقتها وقاعدة بياناتها دون أي شاشة بيضاء!
